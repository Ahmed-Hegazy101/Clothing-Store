# 🛍️ ATELIER Edition — Minimal Clothing Store

A modern, high-end, and fully responsive e-commerce web application designed for a luxury minimal clothing brand. Built with a focus on clean aesthetics, smooth user interactions, and complete bilingual support (English & Arabic with dynamic RTL translation).

---

## ✨ Features

- **🌐 Bilingual Support:** Seamless live translation switching between English and Arabic (RTL layout adjustment).
- **🛒 Interactive Product Catalog:** Dynamic product rendering, category filtering pills, and a "View All" toggle.
- **❤️ Wishlist / Favorites System:** Interactive drawer to add, remove, or move items directly to the cart with badge counters.
- **🛍️ Fully Functional Shopping Cart:** Real-time quantity adjustments, item removal, and live subtotal calculations.
- **💳 Luxury Checkout System:** Tailored checkout options including Egypt shipping and local payment simulations (InstaPay, Vodafone Cash).
- **🔍 Real-Time Search Overlay:** Instant bilingual product filtering as you type.
- **📱 Fully Responsive Design:** Meticulously crafted layout optimized for mobile, tablet, and desktop screens using modern CSS.

---

## 🛠️ Built With

This project was built using core modern web technologies without heavy frameworks:
- **HTML5:** Semantic markup structure.
- **CSS3:** Advanced styling using Flexbox, CSS Grid, and custom variables for a minimalist aesthetic.
- **JavaScript (ES6+):** Dynamic DOM manipulation, asynchronous operations, state management, and localization rendering.
